* The words

| word        | means                                                        |
|-------------+--------------------------------------------------------------|
| surface     | wayland placement: what the compositor shows (:as roles)     |
| panel       | a desktop surface toggled by show/hide                       |
| window      | the Emacs window: a scroll/focus view onto a buffer          |
| window-node | that view embedded as a layout leaf (class name only)        |
| buffer      | content: lines + point + meta, an actor over fset state      |
| layout      | a node tree; a buffer can SHOW one (show-layout,             |
|             | layout-mode, :set-layout, :layout-* meta,                    |
|             | layout-next/prev/activate)                                   |
| render      | layout -> cell rows (+ the arranged tree)                    |
| paint-px    | layout -> pixels (cairo)                                     |
| ref         | reactive value: defref declares, (ref K) reads (tracked),    |
|             | (setf (ref K) V) writes (deduped)                            |
| var         | editor variable: defonce declares, (var k [buf]) reads,      |
|             | (setf (var k [buf])) writes                                  |
| store       | durable value in the daemon's SQLite store: (store K) reads, |
|             | (setf (store K) V) writes; store-push / store-items keep     |
|             | bounded lists; defonce/defref :persist ride it               |
| world       | what restarts restore: registered :save/:restore pairs over  |
|             | (:world NAME) store keys -- buffers, arrangement, scratch    |

Three display layers only: buffer (content) -> window (view) -> surface
(placement). Everything else is content vocabulary. There is no "pane"; no
"cell" outside the render grid.

* The primitives

The runtime exposes three primitives in ~pine.buffer~, also imported into
the scratch default package ~pine-user~: ~buffer~, ~ask~, ~tell~. Everything
REPL-useful is one of these.

* ~buffer~ — coerce anything to a buffer actor

Signature: ~(buffer x)~ → actor or nil.

| X            | Result                                                 |
|--------------+--------------------------------------------------------|
| ~nil~        | ~nil~                                                  |
| string       | lookup by name in current server's buffer-table        |
| ~:current~   | client's current-buffer                                |
| ~:focused~   | focused window's buffer-ref                            |
| actor        | passthrough                                            |

Unknown keywords error immediately — nothing silently falls through.

* ~ask~ — synchronous query

Signature: ~(ask target query &rest args)~ → value.

The first argument (target) selects a dispatch layer:

- ~:server~ — runtime / registry introspection
- ~:client~ — per-session state
- anything else — coerced via ~buffer~, then buffer-level query

Every target supports ~(ask TARGET :describe)~ which returns the list of
valid queries for that target.

** Server queries

~(ask :server QUERY)~

| query            | returns                                    |
|------------------+--------------------------------------------|
| ~:buffers~       | list of buffer names                       |
| ~:clients~       | list of client instances                   |
| ~:modes~         | list of mode keyword names                 |
| ~:commands~      | sorted list of command name strings        |
| ~:faces~         | the faces hash table                       |
| ~:actor-system~  | sento actor-system                         |
| ~:describe~      | the verb list                              |

** Client queries

~(ask :client QUERY)~

| query              | returns                                  |
|--------------------+------------------------------------------|
| ~:current-buffer~  | the buffer actor                         |
| ~:focused-window~  | window object                            |
| ~:windows~         | list of windows                          |
| ~:kill-ring~       | list of strings                          |
| ~:last-command~    | command name string or nil               |
| ~:pending-keys~    | chord typed so far ("C-x") or nil        |
| ~:describe~        | the verb list                            |

For mode lookup: ~(ask :current :mode)~. For current-buffer name:
~(ask :current :name)~. No duplicate shortcuts — drill through.

** Buffer queries

~(ask BUF QUERY &rest ARGS)~ where BUF is string, actor, ~:current~, or
~:focused~.

| query             | args                        | returns                       |
|-------------------+-----------------------------+-------------------------------|
| ~:state~          | —                           | buffer-state                  |
| ~:snapshot~       | —                           | snapshot                      |
| ~:text~           | —                           | whole buffer string           |
| ~:meta~           | —                           | fset:map of locals            |
| ~:name~           | —                           | name string                   |
| ~:mode~           | —                           | mode keyword                  |
| ~:pathname~       | —                           | file path or nil              |
| ~:point~          | —                           | ~(values line col)~           |
| ~:line N~         | N = positional line idx     | string                        |
| ~:local KEY &key default~ | KEY positional        | local value or default        |
| ~:describe~       | —                           | the verb list                 |

The tail of args is always a plist; positional args come first where the
verb takes them.

* ~tell~ — send action

Signature: ~(tell target tag &rest plist)~ → the coerced buffer (or nil).

Coerces TARGET via ~buffer~ and sends ~(list* TAG PLIST)~ to the actor.
~nil~ is a safe no-op.

Messages the buffer actor understands:

| tag                    | plist                               | effect                     |
|------------------------+-------------------------------------+----------------------------|
| ~:insert~              | ~:text STR~                         | insert at point            |
| ~:newline~             | —                                   | insert newline at point    |
| ~:backspace~           | —                                   | delete char before point   |
| ~:delete-region~       | ~:start-line :start-col :end-line :end-col~ | delete range       |
| ~:move-point~          | ~:line :col~                        | set point                  |
| ~:undo~                | —                                   | pop undo ring              |
| ~:set-local~           | ~:key :value~                       | set a buffer-local         |
| ~:get-local~           | ~:key [:default]~ (ask-s)           | read a buffer-local        |
| ~:get-state~           | (ask-s)                             | return buffer-state        |
| ~:get-snapshot~        | (ask-s)                             | return snapshot            |
| ~:get-text~            | (ask-s)                             | return whole text          |
| ~:replace-content~     | ~:content STR~                      | replace buffer contents    |
| ~:append-with-prompt~  | ~:text :prompt~                     | REPL output helper         |
| ~:subscribe~           | ~:renderer REF~                     | register subscriber        |
| ~:unsubscribe~         | ~:renderer REF~                     | remove subscriber          |
| ~:set-highlights~      | ~:highlights LIST~                  | install fresh highlights   |

* Examples

#+begin_src lisp
;; identity and introspection
(ask :server :buffers)         ; => ("scratch" "*terminal*")
(ask :server :commands)
(ask :client :current-buffer)  ; actor ref (prints ugly, correct)
(ask :current :name)           ; => "scratch"
(ask :current :mode)           ; => :text-mode
(ask "*terminal*" :meta)       ; fset:map of locals
(ask "*terminal*" :local :pathname :default "none")
(ask :current :describe)       ; list of buffer verbs

;; mutation
(tell :current :insert :text "hello")
(tell :current :set-local :key :package :value :pine-user)
(tell "*terminal*" :move-point :line 0 :col 0)
#+end_src

* Scratch's default package

The scratch buffer is pinned to ~:pine-user~ at startup (via
~:set-local :key :package :value :pine-user~). ~pine-user~ imports the
three primitives plus common handles from ~pine.client~ and ~pine.mode~.
Unqualified ~ask~, ~tell~, ~buffer~, ~current-client~, ~current-buffer~,
~find-mode~, ~set-buffer-mode~, ~defmode~, ~eval-last-sexp~,
~eval-buffer~ all resolve.

For a different package, ~(tell :current :set-local :key :package :value
:some-package)~.

* Adding new queries

Add the verb to:
1. The corresponding ~+...-verbs+~ list (at the top of ~buffer.lisp~'s
   API section).
2. The ~case~ in the corresponding ~%ask-...~ function.

If the verb takes positional args, use ~(first args)~; if it takes keyword
options, use ~(getf (rest args) :key)~.

Unknown verbs get a readable error listing the known set — no silent
cascades.

* The buffer verb protocol

The verbs a buffer actor answers, layered by mode (dispatch-message methods in
src/mode/edit.lisp). tell sends any of them; ask wraps the synchronous ones.

** base-mode (every buffer)

| verb              | args                        | effect |
|-------------------+-----------------------------+--------|
| =:get-state=      |                             | reply the buffer-state |
| =:get-snapshot=   |                             | reply a snapshot |
| =:get-text=       |                             | reply the full string |
| =:get-local=      | =:key :default=             | reply a meta value |
| =:subscribe=      | =:renderer REF=             | add subscriber, push a snapshot |
| =:unsubscribe=    | =:renderer REF=             | remove subscriber |
| =:set-highlights= | =:highlights RUNS=          | explicit face runs (tool buffers) |
| =:move-point=     | =:line :col=                | set point |
| =:move-by=        | =:unit :n=                  | move point by :char/:word/:line |
| =:ts-motion=      | =:kind=                     | structural motion off the tree |
| =:undo= / =:redo= |                             | history |
| =:set-local= / =:set-meta= | =:key :value=      | set a meta key (:mode reparses) |
| =:set-var=        | =:key :value=               | set a buffer-local variable |
| =:overlay=        | =:line :text [:class]=      | inline annotation after the line (dies on edit) |
| =:clear-overlays= |                             | drop every overlay |
| =:replace-content= | =:content=                 | fresh content, identity kept |
| =:set-layout=       | =:builder :width :selection= | become a layout buffer |
| =:reproject=      | =[:width] [:selection]=     | re-run the stored layout builder |

** text-mode (editable buffers)

| verb              | args                        | effect |
|-------------------+-----------------------------+--------|
| =:insert=         | =:text=                     | insert at point |
| =:newline=        |                             | electric newline (tree indent) |
| =:backspace=      |                             | delete before point |
| =:delete-region=  | =:start-line :start-col :end-line :end-col= | delete range |
| =:indent-lines=   | =[:from] [:to]=             | reindent from the parse tree |
| =:append-with-prompt= | =:text :prompt=         | repl output + fresh prompt |

repl-mode overrides =:newline= (submit); terminal-mode routes =:insert= /
=:newline= / =:backspace= to the pty and ignores the editing verbs.

* The node vocabulary (class / constructor / wire tag)

One tree, three names per node kind: the CLOS class (what typecase sees), the
constructor (what builders call; the user language), and the wire tag
(node->wire / wire->node).

| class       | constructor | wire        |
|-------------+-------------+-------------|
| text-node   | =label= / =icon= | =:label= |
| separator   | =rule=      | =:rule=     |
| spacer      | =gap=       | =:gap=      |
| vstack      | =column=    | =:column=   |
| hstack      | =row=       | =:row=      |
| box         | =boxed=     | =:box=      |
| center      | =centered=  | =:centered= |
| scroll      | =viewport=  | =:viewport= |
| selectable  | =choice=    | =:choice=   |
| action      | =button=    | =:action=   |
| list-node   | =rows=      | =:column=   |
| grid        | (direct)    | =:grid=     |
| slider      | =meter=     | =:meter=    |
| ring        | =ring=      | =:ring=     |
| calendar    | =cal=       | =:calendar= |
| picture     | =pic=       | =:picture=  |
| window-node | =window=    | =:window=   |
| centerbox   | =centerbox= | =:centerbox= |

Two paint targets, one tree: =paint= (cells, via =render=) and =paint-px=
(pixels, cairo). =render root width :selection n= -> (values rows tree): rows
in the frame wire run format, tree arranged for =node-at= position lookup.
