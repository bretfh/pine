#+TITLE: pine substrate performance: hot paths, measured
#+AUTHOR: Bret Horne
#+OPTIONS: toc:3 num:t
#+PROPERTY: header-args:sh :exports both :results output

* Why this document exists

pine's durability model is that the daemon stays up. One headless SBCL image
holds the live world and is meant to outlive every app and agent attached to it.
That makes the daemon a kernel, and it makes one number matter more than raw
speed: the rate at which the hot paths allocate. A function that conses a
megabyte per call is fine in a script that runs once and exits. In a process
that must run for weeks it is a slow leak of time into the garbage collector and
a slow march toward a large, fragmented heap whose full collections are the
pauses a user feels.

So this is not a leaderboard. It measures the daemon's actual hot paths on real
code and reports, for each, three things: time per operation, bytes consed per
operation, and the fraction of wall time spent in GC. The bytes column is the
one to read first.

The first measurement pass found four offenders; all four are fixed and the
before/after tables below are the record. Everything here is reproducible: the
harness and the correctness probes are tangled out of this file (they live at
=bench/=), =make check-bench= proves the rewrites behavior-identical, and
=make bench= refuses to run the numbers on failing probes.

* How to reproduce

#+end_src

Both load the system under the project's guix shell, so grammars and shared

* Where the hot paths live

The daemon never draws. State lives as buffer actors over immutable fset values;
a view is built from a snapshot, serialized to a plain wire value, and shipped to
an app that paints it in its own process. Every edit walks this pipeline. Costs
below are the fixed pipeline at 10,000 lines for buffers and 200 top-level forms
for the highlighter.

** The eval and errors-come-home path

Orthogonal to rendering. Each evaluation is one thread; an error captures its
restarts as data and blocks; a surface picks a restart by name. The same call
against a process agent crosses the remoting wire, which is the price of the
hard crash boundary:

#+begin_example
  evaluate-thunk ---> new thread ---> run ---> on-done       34 us / 132 KB  (in-image)

  agent-eval ---> remoting wire ---> agent image evals ---> result home
                                                            211 us / 18 KB  (cross-process)
                                                            spawn-to-connect: 2.5 s once
#+end_example

An isolated computation that can crash without touching the daemon costs 211
microseconds per eval and 18 KB on the daemon side. Six times an in-image thread
eval's latency, one seventh of its consing. The crash boundary is cheap.

* Method

Each benchmark calls one operation repeatedly. The rep count auto-grows by
factors of four until a timed batch reaches 150 ms, so short operations get
millions of reps and long ones get a handful. For the final batch the harness
records wall time (=get-internal-real-time=), bytes consed
(=sb-ext:get-bytes-consed=, monotonic total allocation, so the delta is exactly
what the loop allocated), and GC time (=sb-ext:*gc-run-time*=). Columns:

- =ns/op= : wall nanoseconds per operation, GC included.
- =bytes/op= : heap bytes allocated per operation.
- =gc%= : percent of the batch's wall time spent collecting.

Correctness is not assumed: =make bench= first runs three probes and aborts on
any failure. A 2000-edit random equivalence test of the buffer ops against a
plain list-of-strings model; golden escape-sequence scripts through the vt
(visible screen, scrollback contents, faces, chunked OSC); and a 200-edit (1000
in stress runs) equivalence test of incremental highlighting against a fresh
full walk, including line-inserting and line-joining edits.

Structural edits went from O(lines) to O(log n): 233 -> 282 -> 328 ns across a

evicts the oldest; the old code silently stopped recording.

** tree-sitter highlighting

#+CAPTION: after (incremental: changed-ranges window, filtered walk, cache merge)
| op                                  |      ns/op |   bytes/op |
|-------------------------------------+------------+------------|
| reparse! full, 200 forms            |    265,633 |     11,168 |
| highlight full walk, 200 forms      | 65,001,750 | 33,344,396 |
| edit+reparse+highlight, 200 forms   |  5,562,656 |  3,118,703 |

The number that matters is the last row: the per-keystroke path (one small
edit, incremental reparse, incremental re-highlight) is 5.6 ms / 3.1 MB against
the 65 ms / 33 MB full walk it replaces -- about 12x on both axes, and the gap
grows with file size because the re-walk is local to the changed top-level
forms while the full walk is linear in the file. The mechanism: =reparse!=
records the changed line span from =ts_tree_get_changed_ranges= unioned with
the raw edit rows, the walker skips subtrees outside that window (context stays
exact because the descent from the root still runs), and cached tuples outside
the window are kept, shifted by the line delta. Any doubt -- two edits between
highlight calls, a window that swallowed most of the file, any error -- falls
back to the full walk. The 1000-edit equivalence probe, including line inserts
and joins, is what makes this trustworthy.

The remaining allocation in both rows is dominated by CFFI by-value TSNode
returns (a plist per node call through libffi), which is the binding style, not
the walk.

*** The window a buffer actually paints

Both rows above highlight the whole file. Nothing reads most of that: a window
paints the lines between its scroll offset and its height, and
=build-highlight-table= drops the rest. So the buffer is told the union of the
line ranges the windows showing it display (=:set-viewport=, sent by the
renderer, which is the only thing that knows a scroll offset), and highlighting
walks that instead.

#+CAPTION: before -> after (viewport walk: binary search to the forms in range, cache keyed by window)
| op                                        | before ns/op | after ns/op | before bytes | after bytes |
|-------------------------------------------+--------------+-------------+--------------+-------------|
| edit+reparse+highlight, 20 forms          |    1,046,891 |     570,321 |      723,285 |     371,096 |
| edit+reparse+highlight, 200 forms         |    6,562,609 |     906,266 |    4,563,674 |     467,008 |
| highlight only, no edit, 20 forms         |    1,046,891 |          54 |      723,285 |           0 |
| highlight only, no edit, 200 forms        |    6,562,609 |         324 |    4,563,674 |           0 |

A keystroke at 200 forms costs 906 us and 467 KB against 6.56 ms and 4.56 MB:
7.2x on time, 9.8x on allocation. A repaint with no edit is a cache hit at 324
ns and no allocation at all. The 20-form rows matter as much as the 200-form
ones: bounding the work to a window must not cost anything on a small file, and
it does not, because the cache is kept per window rather than discarded.

Two things make it sound. The walk reaches the forms in range by binary search
over the root's named nodes instead of descending through every form, since
each node call allocates; and a top-level form has no enclosing context, so
starting the walk at one keeps quote state, depth and head kind exact. Two
properties in =tests/ts.lisp= hold it: a windowed walk agrees with the whole-file
walk on every line inside the window, and it still agrees after a script of
random edits, which is what exercises the cache merge. The merge is only used
when the edit moved no line and landed inside the window; anything else re-walks
the window.

What is left in that 906 us is =reparse!= (254 us of it), which is tree-sitter's
own incremental parse plus the =state->string= that feeds it.

*** The cycle end to end

The rows above measure pieces. This one goes through =refresh-highlights=, the
function the buffer actor calls on every edit of a buffer with a language, so it
includes the buffer's text, the reparse and the highlight together. The
windowless rows are the same cycle with no viewport set, which is what it cost
before.

#+CAPTION: refresh-highlights, one keystroke
| op                        | no window ns/op | window ns/op | no window bytes | window bytes |
|---------------------------+-----------------+--------------+-----------------+--------------|
| 40 forms (~200 lines)     |         781,266 |      269,536 |         597,644 |      170,131 |
| 400 forms (~2,000 lines)  |       7,500,125 |    2,015,656 |       5,745,784 |    1,208,532 |

Two further changes are in those numbers. =state->string= is measured for its

and the indent lookup.

*** What the TSInput callback would not buy

The direction recorded below was to feed tree-sitter through a =TSInput= read
callback so no contiguous copy of the file exists. Measurement says not to. The
copy is =with-foreign-string= inside =reparse!=, and =reparse!= is 254 us for
11 KB, of which a memcpy of 11 KB is single digit microseconds. The cost in that
row is tree-sitter's own incremental parse, not the handoff. A callback from C
into Lisp on every read, with the GC interaction that implies, would buy under a
percent at ordinary file sizes and perhaps a tenth at 400 KB. Not done, and not
worth doing until something shows the copy mattering.

** widget, eval, paint, agent

#+CAPTION: unchanged paths, plus the two previously unmeasured ones
| op                                        |   ns/op | bytes/op |
|-------------------------------------------+---------+----------|
| node->wire (serialize bar)                |     778 |    1,088 |
| wire->node (deserialize bar)              |   8,972 |    5,071 |
| evaluate-thunk round-trip (thread spawn)  |  33,936 |  131,815 |
| paint-tree (bar, 560x120, reused surface) |  96,682 |   16,331 |
| fresh surface + paint + destroy (560x480) | 103,518 |   16,708 |
| process-agent eval round-trip (remoting)  | 210,942 |   18,362 |

The two new measurements close the review's open questions:

- A full app-side frame (measure, arrange, cairo paint) is ~100 us and 16 KB,
  and a fresh surface per frame costs almost nothing over a reused one. The
  event-driven clients repaint on change only; at that rate paint is free, and
  even a 60 fps animation would spend under 1% of a core painting a bar.
- The hard crash boundary costs 211 us and 18 KB per eval on the daemon side.
  Isolation for anything that can loop, eat memory, or segfault is six times an
  in-image eval's latency. Spawn-to-connect for a fresh agent image is 2.5 s,
  paid once per agent (it is a whole SBCL loading :pine).

* What remains, honestly

- =state->string= is still O(n) per call, now 371 us / 1.6 MB at 10k lines
  rather than 601 us / 4.3 MB. It is one allocation of the exact size, so what
  is left is the copy itself. Making it O(edit) means the buffer describing its
  own edits to the parse state rather than handing it a whole string, which is a
  change to how the buffer talks to the parse state and worth doing when files
  get big. The =TSInput= half of that idea is measured and rejected above.
- =%text-edit= still derives the edit by scanning the old and new strings for a
  common prefix and suffix, though the buffer knew exactly what changed. Two
  linear scans of simple strings, so it is small next to the parse; the reason to
  fix it is that the buffer should not have to be diffed to say what it did.
- The highlight full-walk fallback allocates via by-value TSNode plists. A
  pointer-based node representation would cut the walk's consing several-fold;
  that is a bindings rewrite, separate from this work.
- The vt =saved= temp array per scroll (a handful of words) and =render-line='s
  per-line face-change tuples remain; both are noise at current rates.

* Directions log

From the first pass, all landed in this one:

1. load-content one-pass: DONE (fset:convert).
2. Structural edits spliced: DONE (fset insert / less / subseq+concat).
3. Incremental highlights: DONE (changed-ranges + filtered walk + merge,
   equivalence-probed).
4. vt: DONE (ring scrollback with recycling, face interning, OSC fill-pointer
   buffer, SGR straight to stream, speed declaims with safety 1).
5. Daemon heap policy: DONE (=--dynamic-space-size 4096= on daemon/dev).

#+begin_src lisp :tangle ../bench/check.lisp :mkdirp yes
;;;; Correctness probes for the hot-path rewrites. Each probe compares the real
;;;; implementation against a reference model or a golden output and fails
;;;; loudly on divergence. Run before benchmarks: (pine.check:run-checks) exits
;;;; nonzero on failure when invoked via run.lisp / make check-bench.

(defpackage :pine.check
  (:use :cl)
  (:export #:run-checks #:*failures*))

(in-package :pine.check)

(defvar *failures* 0)

(defun fail (fmt &rest args)
  (incf *failures*)
  (format t "~&FAIL: ~?~%" fmt args))

(defun ok (fmt &rest args)
  (format t "~&ok: ~?~%" fmt args))

(defvar *seed* 42)
(defun rnd (n)
  (setf *seed* (mod (+ (* *seed* 1103515245) 12345) (expt 2 31)))
  (mod (floor *seed* 65536) (max 1 n)))

;;;; ---------- probe 1: buffer ops vs list-of-strings reference model ----------

(defun model-string (model)
  (format nil "~{~a~^~%~}" model))

(defun model-insert-string (model l c str)
  (let ((line (nth l model)))
    (append (subseq model 0 l)
            (list (concatenate 'string (subseq line 0 c) str (subseq line c)))
            (subseq model (1+ l)))))

(defun model-insert-newline (model l c)
  (let ((line (nth l model)))
    (append (subseq model 0 l)
            (list (subseq line 0 c) (subseq line c))
            (subseq model (1+ l)))))

(defun model-delete-char (model l c)
  (let ((line (nth l model)))
    (cond ((< c (length line))
           (append (subseq model 0 l)
                   (list (concatenate 'string (subseq line 0 c) (subseq line (1+ c))))
                   (subseq model (1+ l))))
          ((< (1+ l) (length model))
           (append (subseq model 0 l)
                   (list (concatenate 'string line (nth (1+ l) model)))
                   (subseq model (+ 2 l))))
          (t model))))

(defun model-delete-region (model sl sc el ec)
  (let* ((first (nth sl model)) (last (nth el model)))
    (append (subseq model 0 sl)
            (list (concatenate 'string
                               (subseq first 0 (min sc (length first)))
                               (subseq last (min ec (length last)))))
            (subseq model (1+ el)))))

(defun check-buffer-model (&key (edits 2000))
  (let* ((state (pine.text.buffer:load-content (format nil "alpha~%beta~%gamma")))
         (model (list "alpha" "beta" "gamma")))
    (dotimes (i edits)
      (let* ((nlines (length model))
             (l (rnd nlines))
             (line (nth l model))
             (c (rnd (1+ (length line))))
             (op (rnd 5)))
        (case op
          (0 (setf state (pine.text.buffer:insert-string state l c "xy")
                   model (model-insert-string model l c "xy")))
          (1 (setf state (pine.text.buffer:insert-char state l c #\z)
                   model (model-insert-string model l c "z")))
          (2 (setf state (pine.text.buffer:insert-newline state l c)
                   model (model-insert-newline model l c)))
          (3 (setf state (pine.text.buffer:delete-char state l c)
                   model (model-delete-char model l c)))
          (4 (let* ((el (min (1- nlines) (+ l (rnd 3))))
                    (eline (nth el model))
                    (ec (if (= el l) (min (1+ c) (length eline)) (rnd (1+ (length eline)))))
                    (sc (if (= el l) (min c ec) c)))
               (setf state (pine.text.buffer:delete-region state l sc el ec)
                     model (model-delete-region model l sc el ec)))))
        (let ((got (pine.text.buffer:state->string state))
              (want (model-string model)))
          (unless (string= got want)
            (fail "buffer model diverged at edit ~d (op ~d l ~d c ~d):~%  got  ~s~%  want ~s"
                  i op l c got want)
            (return-from check-buffer-model)))))
    (ok "buffer model: ~d random edits, state->string agrees" edits))
  (dolist (text (list "" "one" (format nil "a~%b") (format nil "a~%b~%")
                      (format nil "~%~%") (format nil "trail sp ~%  lead")))
    (let ((got (pine.text.buffer:state->string (pine.text.buffer:load-content text))))
      (unless (string= got text)
        (fail "load-content round-trip ~s -> ~s" text got))))
  (ok "load-content round-trips")
  ;; word motion: exact landings on known text (hyphen splits words)
  (let* ((st (pine.text.buffer:move-mark
              (pine.text.buffer:load-content (format nil "foo bar-baz  qux~%next line"))
              :point 0 0))
         (snap (pine.text.buffer:state->snapshot st)))
    (loop for (n wl wc) in '((1 0 3) (2 0 7) (3 0 11) (4 0 16))
          do (multiple-value-bind (l c) (pine.text.buffer:point-after-move snap :word n)
               (unless (and (= l wl) (= c wc))
                 (fail "word fwd ~d: got (~d ~d) want (~d ~d)" n l c wl wc))))
    (let ((end (pine.text.buffer:state->snapshot (pine.text.buffer:move-mark st :point 1 9))))
      (multiple-value-bind (l c) (pine.text.buffer:point-after-move end :word -2)
        (unless (and (= l 1) (= c 0))
          (fail "word back -2: got (~d ~d) want (1 0)" l c)))))
  (ok "word motion lands exactly"))

;;;; ---------- probe 2: vt golden outputs ----------

(defparameter *vt-script*
  (format nil "plain text line~%~c[31mred~c[0m normal ~c[1;4;32mbold-ul-green~c[0m~%~c]0;my-title~c~c[2J~c[Htop-left after clear~%~c[31;44mcolored~c[m done"
          #\escape #\escape #\escape #\escape
          #\escape #\bel
          #\escape #\escape
          #\escape #\escape))

(defun feed-lines (term n)
  (dotimes (i n)
    (pine.vt:term-process-output term (format nil "line-~d~%" i))))

(defun vt-visible (term)
  "Screen dump with per-row right padding and trailing blank rows removed."
  (string-trim '(#\newline)
               (with-output-to-string (o)
                 (with-input-from-string (i (pine.vt:term-dump-to-string term))
                   (loop for line = (read-line i nil) while line
                         do (write-line (string-right-trim " " line) o))))))

(defun check-vt-golden ()
  ;; golden 1: sgr + osc + clear script
  (let ((term (pine.vt:make-term :width 40 :height 6)))
    (pine.vt:term-process-output term *vt-script*)
    (let ((visible (vt-visible term))
          (title (pine.vt:term-title term)))
      (unless (string= title "my-title")
        (fail "vt title: got ~s want ~s" title "my-title"))
      (unless (string= visible (format nil "top-left after clear~%colored done"))
        (fail "vt script visible: got ~s" visible))
      (let* ((row (pine.vt:term-grid-row term 1))
             (cell (aref row 0))
             (face (pine.vt:cell-face cell)))
        (unless (and face (eql (pine.vt:face-fg face) 1) (eql (pine.vt:face-bg face) 4))
          (fail "vt face on 'colored': got fg=~s bg=~s"
                (and face (pine.vt:face-fg face)) (and face (pine.vt:face-bg face))))))
    (ok "vt sgr/osc/clear golden"))
  ;; golden 2: scroll pushes exact rows to scrollback, visible window correct.
  ;; Stays below the scrollback cap so the expectation holds for any eviction
  ;; policy at the cap.
  (let ((term (pine.vt:make-term :width 20 :height 4 :max-scrollback 8)))
    (feed-lines term 10)
    (let ((visible (vt-visible term)))
      (unless (string= visible (format nil "line-7~%line-8~%line-9"))
        (fail "vt scroll visible: got ~s" visible)))
    (let ((n (pine.vt::term-scrollback-size term)))
      (unless (= n 7)
        (fail "vt scrollback size: got ~d want 7" n))
      (dotimes (i (min n 7))
        (let* ((head (if (fboundp 'pine.vt::term-scrollback-head)
                         (funcall 'pine.vt::term-scrollback-head term)
                         0))
               (row (aref (pine.vt::term-scrollback term)
                          (mod (+ head i)
                               (length (pine.vt::term-scrollback term)))))
               (text (string-trim " "
                       (map 'string #'pine.vt:cell-char row))))
          (unless (string= text (format nil "line-~d" i))
            (fail "vt scrollback[~d]: got ~s want ~s" i text (format nil "line-~d" i))))))
    (ok "vt scroll golden"))
  ;; golden 3: chunked OSC (split escape) still parses
  (let ((term (pine.vt:make-term :width 20 :height 4)))
    (pine.vt:term-process-output term (format nil "~c]0;half" #\escape))
    (pine.vt:term-process-output term (format nil "-and-half~c" #\bel))
    (unless (string= (pine.vt:term-title term) "half-and-half")
      (fail "vt chunked osc title: got ~s" (pine.vt:term-title term)))
    (ok "vt chunked-osc golden"))
  ;; golden 4: render-line reports face runs at the right columns
  (let ((term (pine.vt:make-term :width 20 :height 2)))
    (pine.vt:term-process-output term (format nil "ab~c[7mcd~c[0mef" #\escape #\escape))
    (multiple-value-bind (chars changes) (pine.vt:term-render-line term 0)
      (unless (string= (subseq chars 0 6) "abcdef")
        (fail "vt render-line chars: got ~s" (subseq chars 0 6)))
      ;; captured golden: runs at 0 (default), 2 (inverse), 4 (default written),
      ;; 6 (untouched cells, nil face)
      (unless (and (= (length changes) 4)
                   (equal (first (second changes)) 2)
                   (equal (second (second changes)) '(:inverse t)))
        (fail "vt render-line runs: got ~s" changes)))
    (ok "vt render-line golden")))

;;;; ---------- probe 3: incremental highlights == full walk ----------

(defun random-lisp-text (nforms)
  (with-output-to-string (o)
    (dotimes (i nforms)
      (format o "(defun fn~d (a b)~%  \"doc ~d\"~%  (let ((x (+ a ~d)))~%    (* x b)))~%~%"
              i i i))))

(defun mutate-line (text)
  "One random edit of TEXT: char insert/delete/replace, newline insert (shifts
every following line), or newline delete (joins two lines). The newline ops
exercise the nonzero line-delta paths of incremental highlighting."
  (let* ((len (length text))
         (pos (rnd (max 1 len))))
    (case (rnd 5)
      (0 (concatenate 'string (subseq text 0 pos) "q" (subseq text pos)))
      (1 (if (and (plusp len) (char/= (char text pos) #\newline))
             (concatenate 'string (subseq text 0 pos) (subseq text (min len (1+ pos))))
             text))
      (2 (if (and (plusp len) (char/= (char text pos) #\newline))
             (concatenate 'string (subseq text 0 pos) "w" (subseq text (min len (1+ pos))))
             text))
      (3 (concatenate 'string (subseq text 0 pos) (string #\newline)
                      (subseq text pos)))
      (4 (let ((nl (position #\newline text :start pos)))
           (if nl
               (concatenate 'string (subseq text 0 nl) (subseq text (1+ nl)))
               text))))))

(defun sort-highlights (hl)
  (sort (copy-list hl)
        (lambda (a b)
          (or (< (first a) (first b))
              (and (= (first a) (first b))
                   (or (< (second a) (second b))
                       (and (= (second a) (second b))
                            (string< (princ-to-string a) (princ-to-string b)))))))))

(defun check-highlights (&key (edits 200))
  (handler-case
      (let* ((rt (pine.ts.runtime:make-ts-runtime))
             (inc (pine.ts.runtime:make-parse-state rt :commonlisp))
             (text (random-lisp-text 12)))
        (unless inc
          (ok "highlights probe skipped: no commonlisp grammar")
          (return-from check-highlights))
        (pine.ts.runtime:parse-full! inc text)
        (pine.ts.runtime:parse-highlights inc text)
        (dotimes (i edits)
          (setf text (mutate-line text))
          (pine.ts.runtime:reparse! inc text)
          (let* ((got (sort-highlights (pine.ts.runtime:parse-highlights inc text)))
                 (fresh (pine.ts.runtime:make-parse-state rt :commonlisp)))
            (pine.ts.runtime:parse-full! fresh text)
            (let ((want (sort-highlights (pine.ts.runtime:parse-highlights fresh text))))
              (pine.ts.runtime:free-parse-state fresh)
              (unless (equal got want)
                (fail "highlights diverged at edit ~d:~%  extra ~s~%  missing ~s"
                      i (set-difference got want :test #'equal)
                      (set-difference want got :test #'equal))
                (return-from check-highlights)))))
        (pine.ts.runtime:free-parse-state inc)
        (ok "highlights: ~d random edits, incremental == full walk" edits)
        ;; same equivalence over a real source file: real files carry the
        ;; constructs generators miss (comments, loop clauses, format strings)
        (let ((path (probe-file "src/buffer/buffer.lisp")))
          (when path
            (let ((real (with-open-file (s path)
                          (let ((str (make-string (file-length s))))
                            (subseq str 0 (read-sequence str s)))))
                  (inc2 (pine.ts.runtime:make-parse-state rt :commonlisp)))
              (pine.ts.runtime:parse-full! inc2 real)
              (pine.ts.runtime:parse-highlights inc2 real)
              (dotimes (i 150)
                (setf real (mutate-line real))
                (pine.ts.runtime:reparse! inc2 real)
                (let* ((got (sort-highlights (pine.ts.runtime:parse-highlights inc2 real)))
                       (fresh (pine.ts.runtime:make-parse-state rt :commonlisp)))
                  (pine.ts.runtime:parse-full! fresh real)
                  (let ((want (sort-highlights (pine.ts.runtime:parse-highlights fresh real))))
                    (pine.ts.runtime:free-parse-state fresh)
                    (unless (equal got want)
                      (fail "real-file highlights diverged at edit ~d" i)
                      (return)))))
              (pine.ts.runtime:free-parse-state inc2)
              (ok "highlights: 150 real-file edits, incremental == full walk")))))
    (error (e) (ok "highlights probe skipped: ~a" e))))

;;;; ---------- probe 4: tree-driven indentation ----------

(defun check-indent ()
  (handler-case
      (let* ((rt (pine.ts.runtime:make-ts-runtime))
             (ps (pine.ts.runtime:make-parse-state rt :commonlisp)))
        (unless ps
          (ok "indent probe skipped: no commonlisp grammar")
          (return-from check-indent))
        (let ((text (format nil "(defun f (x)~%(let ((a 1)~%(b 2))~%(+ a~%b)))~%(foo bar~%baz)")))
          (pine.ts.runtime:parse-full! ps text)
          (let ((got (loop for i from 0 to 6 collect (pine.ts.runtime:parse-indent ps i)))
                (want '(0 2 6 2 3 0 5)))
            (if (equal got want)
                (ok "indent: nested body + argument-alignment columns")
                (fail "indent columns: got ~s want ~s" got want))))
        (let ((ps2 (pine.ts.runtime:make-parse-state rt :commonlisp))
              (s (concatenate 'string "(defvar *x*" (string #\Newline)
                              (string #\") "a" (string #\Newline) "b"
                              (string #\") (string #\Newline) "1)")))
          (pine.ts.runtime:parse-full! ps2 s)
          (let ((got (loop for i from 0 to 3 collect (pine.ts.runtime:parse-indent ps2 i))))
            (if (equal got '(0 2 nil 2))
                (ok "indent: multiline-string interior left as-is")
                (fail "indent string interior: got ~s" got))
            (pine.ts.runtime:free-parse-state ps2)))
        (let ((ps3 (pine.ts.runtime:make-parse-state rt :commonlisp)))
          (pine.ts.runtime:parse-full! ps3 (format nil "(defcommand foo ()~%(bar))"))
          (unless (equal (list (pine.ts.runtime:parse-indent ps3 0) (pine.ts.runtime:parse-indent ps3 1))
                         '(0 2))
            (fail "indent user def-macro body"))
          (pine.ts.runtime:free-parse-state ps3))
        (pine.ts.runtime:free-parse-state ps)
        (let ((st (pine.text.buffer:load-content (format nil "(foo~%  bar)"))))
          (multiple-value-bind (new col) (pine.text.buffer:reindent-line st 1 2 5 4)
            (unless (and (= col 7)
                         (string= (pine.text.buffer:state->string new)
                                  (format nil "(foo~%     bar)")))
              (fail "reindent-line: ~s col ~s" (pine.text.buffer:state->string new) col))))
        (ok "indent: reindent-line rewrites leading ws"))
    (error (e) (ok "indent probe skipped: ~a" e))))

#+begin_src lisp :tangle ../bench/bench.lisp :mkdirp yes
;;;; Hot-path microbenchmarks for the pine substrate. Each bench reports ns/op,
;;;; bytes consed/op, and the GC fraction of wall time, because allocation rate
;;;; is the property that matters for a daemon meant never to restart. Load :pine
;;;; and :pine/vt first (run.lisp does), then (pine.bench:run-all).

(defpackage :pine.bench
  (:use :cl)
  (:export #:run-all #:run-bench #:*target-ms*))

(in-package :pine.bench)

(defvar *target-ms* 150
  "Grow rep count until a timed batch reaches at least this many ms.")

(defstruct row label reps ns/op bytes/op gc-ms total-ms)

(declaim (inline %now))
(defun %now () (get-internal-real-time))
(defun %ms (ticks) (* 1000d0 (/ ticks internal-time-units-per-second)))

(defun run-bench (label thunk &key (target-ms *target-ms*))
  (funcall thunk)
  (let ((reps 1))
    (loop
      (let ((b0 (sb-ext:get-bytes-consed))
            (g0 sb-ext:*gc-run-time*)
            (t0 (%now)))
        (dotimes (i reps) (funcall thunk))
        (let* ((dt (- (%now) t0))
               (ms (%ms dt)))
          (when (or (>= ms target-ms) (>= reps 200000000))
            (return
              (make-row :label label :reps reps
                        :ns/op (/ (* ms 1d6) reps)
                        :bytes/op (/ (- (sb-ext:get-bytes-consed) b0) (float reps 1d0))
                        :gc-ms (%ms (- sb-ext:*gc-run-time* g0))
                        :total-ms ms)))
          (setf reps (* reps 4)))))))

(defmacro defbench (label &body body)
  `(run-bench ,label (lambda () ,@body)))

(defun print-table (title rows)
  (format t "~&~%#+CAPTION: ~a~%" title)
  (format t "| op | reps | ns/op | bytes/op | gc% |~%")
  (format t "|-~%")
  (dolist (r rows)
    (when r
      (format t "| ~a | ~:d | ~:d | ~:d | ~,1f |~%"
              (row-label r) (row-reps r)
              (round (row-ns/op r)) (round (row-bytes/op r))
              (if (plusp (row-total-ms r))
                  (* 100d0 (/ (row-gc-ms r) (row-total-ms r))) 0d0))))
  (finish-output))

(defun a-line (cols i)
  (let ((s (make-string cols)))
    (dotimes (c cols s) (setf (char s c) (code-char (+ 97 (mod (+ i c) 26)))))))

(defun lines-state (nlines &optional (cols 40))
  (let ((seq (fset:empty-seq)))
    (dotimes (i nlines) (setf seq (fset:with-last seq (a-line cols i))))
    (make-instance 'pine.text.buffer:buffer-state
                   :lines seq
                   :meta (fset:with (fset:empty-map) :name "bench"))))

(defun lisp-source (nforms)
  (with-output-to-string (o)
    (dotimes (i nforms)
      (format o "(defun f~d (x y)~%  (let ((z (+ x y)))~%    (* z ~d)))~%~%" i i))))

(defun sample-tree ()
  (apply #'pine.ui.node:row
         (append (loop repeat 8 collect (pine.ui.node:label "item"))
                 (list (pine.ui.node:meter :value 42 :min 0 :max 100)
                       (pine.ui.node:meter :value 70 :min 0 :max 100)))))

(defparameter *plain-chunk*
  (with-output-to-string (o)
    (dotimes (i 40)
      (format o "the quick brown fox jumps over the lazy dog line ~d~%" i))))

(defparameter *sgr-chunk*
  (with-output-to-string (o)
    (dotimes (i 40)
      (dotimes (w 9) (format o "~c[3~dmword~c[0m " #\escape (1+ (mod w 6)) #\escape))
      (terpri o))))

(defun bench-buffer ()
  (let (rows)
    (dolist (n '(100 1000 10000))
      (let* ((st (lines-state n))
             (mid (floor n 2)))
        (push (defbench (format nil "insert-char @mid, ~d lines" n)
                (pine.text.buffer:insert-char st mid 0 #\x)) rows)
        (push (defbench (format nil "insert-newline @mid, ~d lines" n)
                (pine.text.buffer:insert-newline st mid 5)) rows)
        (push (defbench (format nil "delete-region 3ch @mid, ~d lines" n)
                (pine.text.buffer:delete-region st mid 0 mid 3)) rows)
        (push (defbench (format nil "state->snapshot, ~d lines" n)
                (pine.text.buffer:state->snapshot st)) rows)
        (push (defbench (format nil "state->string, ~d lines" n)
                (pine.text.buffer:state->string st)) rows)))
    (print-table "buffer edits (fset immutable state)" (nreverse rows))))

(defun bench-load-content ()
  (let (rows)
    (dolist (n '(100 1000 5000))
      (let ((text (with-output-to-string (o)
                    (dotimes (i n) (write-line (a-line 40 i) o)))))
        (push (defbench (format nil "load-content, ~d lines" n)
                (pine.text.buffer:load-content text)) rows)))
    (print-table "load-content (file open path)" (nreverse rows))))

(defun bench-vt ()
  (let* ((term (pine.vt:make-term :width 80 :height 24)) rows)
    (push (defbench (format nil "process-output plain (~d B)" (length *plain-chunk*))
            (pine.vt:term-process-output term *plain-chunk*)) rows)
    (push (defbench (format nil "process-output sgr (~d B)" (length *sgr-chunk*))
            (pine.vt:term-process-output term *sgr-chunk*)) rows)
    (push (defbench "render-line (one row)" (pine.vt:term-render-line term 0)) rows)
    (push (defbench "dump-to-string (full 80x24)" (pine.vt:term-dump-to-string term)) rows)
    (print-table "vt terminal (mutable cell grid)" (nreverse rows))))

(defun %safe (thunk)
  (handler-case (funcall thunk)
    (error (e) (format t "~&  (bench skipped: ~a)~%" e) nil)))

(defun bench-widget ()
  (let ((pine.core.server:*server* (make-instance 'pine.core.server:server)))
    (let* ((tree (sample-tree))
           (wire (pine.ui.node:node->wire tree)) rows)
      (push (%safe (lambda () (defbench "node->wire (serialize bar)"
                                (pine.ui.node:node->wire tree)))) rows)
      (push (%safe (lambda () (defbench "wire->node (deserialize bar)"
                                (pine.ui.node:wire->node wire)))) rows)
      (push (%safe (lambda () (defbench "node-to-string (render bar, w=80)"
                                (pine.ui.node:node-to-string tree 80)))) rows)

(defun bench-ts ()
  (handler-case
      (let* ((rt (pine.ts.runtime:make-ts-runtime)) rows)
        (dolist (n '(20 200))
          (let* ((text (lisp-source n))
                 (ps (pine.ts.runtime:make-parse-state rt :commonlisp)))
            (unless ps (error "no commonlisp grammar"))
            (pine.ts.runtime:parse-full! ps text)
            (push (defbench (format nil "reparse! full, ~d forms (~d B)" n (length text))
                    (pine.ts.runtime:reparse! ps text)) rows)
            (push (defbench (format nil "highlight full walk, ~d forms" n)
                    (progn (setf (pine.ts.runtime::ps-hl-cache ps) nil)
                           (pine.ts.runtime:parse-highlights ps text))) rows)
            ;; the typing path: one small edit, reparse, re-highlight
            (let* ((mid (floor (length text) 2))
                   (alt (concatenate 'string (subseq text 0 mid) "x" (subseq text mid)))
                   (cur text))
              (pine.ts.runtime:reparse! ps cur)
              (pine.ts.runtime:parse-highlights ps cur)
              (push (defbench (format nil "edit+reparse+highlight, ~d forms" n)
                      (progn (setf cur (if (eq cur text) alt text))
                             (pine.ts.runtime:reparse! ps cur)
                             (pine.ts.runtime:parse-highlights ps cur)))
                    rows))))
        (print-table "tree-sitter reparse + highlight" (nreverse rows)))
    (error (e) (format t "~&(ts group skipped: ~a)~%" e))))

    (print-table "eval path (one thread per evaluation)" (nreverse rows))))

(defun bench-agent ()
  "The crash-boundary cost: spawn a real SBCL process agent over remoting and
measure the eval round-trip (serialize, send, eval in the other image, result
home). Spawn-to-connect is reported once; it is a fresh image loading :pine."
  (handler-case
      (let ((srv (pine.core.server:start-server :remoting-port 18191)))
        (setf pine.core.server:*server* srv)
        (pine.core.actor:start-agent-registry srv)
        (pine.core.actor:start-agent-debug srv)
        (setf pine.core.actor::*agent-port* 18191)
        (let ((sem (sb-thread:make-semaphore))
              (t0 (get-internal-real-time)))
          (setf pine.core.actor:*agent-debug-hook*
                (lambda (msg)
                  (when (eq (first msg) :agent-result)
                    (sb-thread:signal-semaphore sem))))
          (let ((info (pine.core.actor:spawn-agent srv "bench-agent")))
            (format t "~&agent spawn-to-connect: ~,1fs (fresh SBCL image loading :pine)~%"
                    (/ (float (- (get-internal-real-time) t0) 1d0)
                       internal-time-units-per-second))
            (unwind-protect
                 (let (rows)
                   (push (defbench "process-agent eval round-trip (remoting)"
                           (progn (pine.core.actor:agent-eval srv info "42")
                                  (sb-thread:wait-on-semaphore sem :timeout 30)))
                         rows)
                   (print-table "process agent (the crash boundary)" (nreverse rows)))
              (pine.core.actor:unsupervise-agent "bench-agent")
              (ignore-errors (sento.actor:tell (pine.core.actor:agent-info-actor info) '(:crash)))
              (ignore-errors (pine.core.actor:unregister-agent srv "bench-agent"))))))
    (error (e) (format t "~&(agent group skipped: ~a)~%" e))))

(defun machine-header ()
  (format t "~&#+BEGIN_EXAMPLE~%")
  (format t "sbcl:   ~a~%" (lisp-implementation-version))
  (ignore-errors
   (with-open-file (f "/proc/cpuinfo" :if-does-not-exist nil)
     (when f
       (loop for line = (read-line f nil) while line
             when (and (> (length line) 10) (string= "model name" line :end2 10))
               do (format t "cpu:   ~a~%"
                          (string-trim " " (subseq line (1+ (position #\: line)))))
                  (return)))))
  (format t "target-ms per bench: ~d~%" *target-ms*)
  (format t "#+END_EXAMPLE~%"))
