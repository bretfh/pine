design that is not built yet, and says which it is at the top. Nothing tracks
progress: what is done is what the tree does.

* Lineage

The tree before the namespace rewrite. The principles hold and
=new-architecture.org= says which ones; the vocabulary is gone.

| doc                | what it was                                                |
|--------------------+------------------------------------------------------------|
| [[file:architecture.org][architecture.org]]   | the registry that brokered capabilities, buffers as actors, reactive cells |
| [[file:performance.org][performance.org]]    | what the hot paths of that tree cost, and how they were measured |
| [[file:pine.org][pine.org]]           | the manual for that tree, by concept. It names packages the rewrite deleted, and documents no longer here |

=api.org=, =pine-user.org= and =theming.org= are gone rather than kept as
lineage: each described a vocabulary =new-api.org= replaced outright, and a
document that reads as instructions is worse than no document when it is wrong.
