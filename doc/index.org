#+TITLE: pine docs
#+AUTHOR: Bret Horne

Every document is here, flat. A document explains code that exists or states a
design that is not built yet, and says which it is at the top. Nothing tracks
progress: what is done is what the tree does.

in the tree now. They are the reasoning, not a description of the code: read
=src/= for what it does.
